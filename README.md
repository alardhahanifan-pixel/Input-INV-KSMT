# 🌾 Input Invoice Penjualan KSMT

Aplikasi Streamlit untuk mengekstrak data dari foto invoice (via OCR.Space) dan mengubahnya menjadi format Excel rekap otomatis.

## 🚀 Fitur
- Tema gelap profesional
- Logo padi elegan
- Upload file `.zip` berisi foto invoice
- Otomatis ekstrak teks dengan OCR.Space (gratis)
- Hasil bisa langsung diunduh sebagai Excel

## ⚙️ Cara Menjalankan
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📄 Catatan
Gunakan API key gratis dari [ocr.space](https://ocr.space/ocrapi) jika ingin hasil lebih akurat.
